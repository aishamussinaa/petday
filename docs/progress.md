Миграция применена; старые completedAt перенесены в completedCount=1. Отдельные счётчики на каждый день, атомарные версии и история изменений; будущие выполнения запрещены. Тестовый API теперь запускается без --watch и с отдельной проверкой готовности, чтобы генерация Prisma не перезапускала сервер посреди запроса. Новые проверки: tests/recurring.spec.js.
